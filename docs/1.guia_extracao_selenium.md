# Guia de Extração de CSVs com Selenium

## Contexto

Este guia documenta o desenvolvimento dos scripts Python de extração automatizada de relatórios CSV do sistema de gestão da oficina. Cada relatório é extraído por um script independente, o que facilita reprocessamento individual e futura integração com o Apache Airflow.

---

| Script                          | Relatório              | Subdiretório       | Encoding |
|---------------------------------|------------------------|--------------------|----------|
| `extract_clientes.py`           | clientes               | `clientes/`        | utf-8    |
| `extract_motocicletas.py`       | motocicletas           | `motocicletas/`    | utf-8    |
| `extract_ordens_de_servico.py`  | ordens_de_servico      | `ordens/`          | utf-8    |
| `extract_itens_os.py`           | itens_ordem_de_servico | `itens_os/`        | cp1252   |
| `extract_produtos.py`           | produtos               | `produtos/`        | utf-8    |
| `extract_servicos.py`           | serviços               | `servicos/`        | utf-8    |

---

## Estrutura de cada script

Cada script é **autocontido**: faz login, navega, configura o filtro de data, dispara o download e valida o arquivo. Nenhum estado (driver, sessão) é compartilhado entre scripts.

```
Script
 └── run_extraction()
      ├── 1. Carregar variáveis do .env
      ├── 2. Montar o caminho de download (base + subdiretório + nome do arquivo)
      ├── 3. Configurar o Chrome (diretório de download)
      ├── 4. Login
      ├── 5. Navegar até o relatório
      ├── 6. Selecionar data / intervalo
      ├── 7. Clicar em exportar
      ├── 8. Aguardar o download terminar
      └── 9. Renomear / validar e encerrar o driver
```

## Configuração do Chrome

O diretório de download deve ser definido via `ChromeOptions` **antes** de iniciar o driver. O Chrome precisa do caminho **absoluto** — por isso usamos `os.path.abspath`.

```python
def configurar_driver(download_dir: str) -> webdriver.Chrome:
    os.makedirs(download_dir, exist_ok=True)  # cria o subdiretório se não existir
    options = Options()
    options.add_experimental_option("prefs", {
        "download.default_directory": os.path.abspath(download_dir),
        "download.prompt_for_download": False,
        "download.directory_upgrade": True,
        "safebrowsing.enabled": True,
    })
    # options.add_argument("--headless")  # descomente após validar visualmente
    return webdriver.Chrome(
        service=Service(ChromeDriverManager().install()),
        options=options,
    )
```

> **Dica:** deixe o `--headless` comentado durante o desenvolvimento. Só ative depois que o script estiver funcionando visualmente.

## Aguardar o download e renomear

O Chrome salva o arquivo com o nome original do sistema. A função abaixo espera o arquivo aparecer e em seguida o renomeia para o nome definido em `NOME_ARQUIVO`.

```python
import time
import glob
import shutil

def aguardar_e_renomear(download_dir: str, nome_final: str, timeout: int = 30) -> str:
    """
    Aguarda um .csv aparecer no diretório, renomeia para nome_final
    e retorna o caminho definitivo.
    """
    inicio = time.time()
    while True:
        arquivos = [
            f for f in glob.glob(os.path.join(download_dir, "*.csv"))
            if not f.endswith(".crdownload")
        ]
        if arquivos:
            arquivo_baixado = max(arquivos, key=os.path.getctime)
            destino = os.path.join(download_dir, nome_final)
            shutil.move(arquivo_baixado, destino)
            return destino

        if time.time() - inicio > timeout:
            raise TimeoutError(f"Download não concluído em {timeout}s")

        time.sleep(1)
```

## Template completo de um script

Abaixo o template para `extract_servicos.py`. Para cada novo script, altere apenas a linha marcada com `# <-- ALTERAR`.

```python
import os
import glob
import time
import shutil
from datetime import date, timedelta

from dotenv import load_dotenv
from selenium import webdriver
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.chrome.service import Service
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from webdriver_manager.chrome import ChromeDriverManager

# ── Variáveis de ambiente ────────────────────────────────────────────────────
load_dotenv()

LOGIN_URL     = os.environ["SISTEMA_LOGIN_URL"]
RELATORIO_URL = "https://url-do-sistema.com/relatorio/servicos"  # <-- ALTERAR
USUARIO       = os.environ["SISTEMA_USUARIO"]
SENHA         = os.environ["SISTEMA_SENHA"]

DOWNLOAD_DIR  = os.path.join(os.environ["DOWNLOAD_BASE"], "servicos")  # <-- ALTERAR

# Janela de extração — últimos 7 dias
hoje         = date.today()
DATA_FIM     = hoje.strftime("%d/%m/%Y")
DATA_INICIO  = (hoje - timedelta(days=7)).strftime("%d/%m/%Y")
NOME_ARQUIVO = f"{hoje.isoformat()}.csv"   # ex: "2026-06-08.csv"


# ── Utilitários ──────────────────────────────────────────────────────────────
def configurar_driver(download_dir: str) -> webdriver.Chrome:
    os.makedirs(download_dir, exist_ok=True)
    options = Options()
    options.add_experimental_option("prefs", {
        "download.default_directory": os.path.abspath(download_dir),
        "download.prompt_for_download": False,
        "download.directory_upgrade": True,
        "safebrowsing.enabled": True,
    })
    # options.add_argument("--headless")
    return webdriver.Chrome(
        service=Service(ChromeDriverManager().install()),
        options=options,
    )


def aguardar_e_renomear(download_dir: str, nome_final: str, timeout: int = 30) -> str:
    inicio = time.time()
    while True:
        arquivos = [
            f for f in glob.glob(os.path.join(download_dir, "*.csv"))
            if not f.endswith(".crdownload")
        ]
        if arquivos:
            arquivo_baixado = max(arquivos, key=os.path.getctime)
            destino = os.path.join(download_dir, nome_final)
            shutil.move(arquivo_baixado, destino)
            return destino
        if time.time() - inicio > timeout:
            raise TimeoutError(f"Download não concluído em {timeout}s")
        time.sleep(1)


# ── Extração ─────────────────────────────────────────────────────────────────
def run_extraction():
    driver = configurar_driver(DOWNLOAD_DIR)
    wait   = WebDriverWait(driver, 15)

    try:
        # 1. Login
        driver.get(LOGIN_URL)
        wait.until(EC.presence_of_element_located((By.ID, "username"))).send_keys(USUARIO)
        driver.find_element(By.ID, "password").send_keys(SENHA)
        driver.find_element(By.ID, "btn-login").click()
        wait.until(EC.presence_of_element_located((By.ID, "menu-principal")))

        # 2. Navegar até o relatório
        driver.get(RELATORIO_URL)

        # 3. Selecionar datas (ajuste os seletores)
        driver.find_element(By.ID, "data_inicio").send_keys(DATA_INICIO)
        driver.find_element(By.ID, "data_fim").send_keys(DATA_FIM)

        # 4. Exportar
        wait.until(EC.element_to_be_clickable((By.ID, "btn-exportar"))).click()

        # 5. Aguardar, renomear e confirmar
        caminho = aguardar_e_renomear(DOWNLOAD_DIR, NOME_ARQUIVO)
        print(f"[OK] Arquivo salvo em: {caminho}")
        print(f"[OK] Período extraído: {DATA_INICIO} → {DATA_FIM}")

    finally:
        driver.quit()


if __name__ == "__main__":
    run_extraction()
```

## O que muda de script para script

Apenas **uma linha** muda entre os 6 scripts — o subdiretório de download e a URL do relatório:

| Script                         | `RELATORIO_URL`              | `DOWNLOAD_DIR` (subdir) |
|--------------------------------|------------------------------|--------------------------|
| `extract_clientes.py`          | `.../relatorio/clientes`     | `clientes/`              |
| `extract_motocicletas.py`      | `.../relatorio/motocicletas` | `motocicletas/`          |
| `extract_ordens_de_servico.py` | `.../relatorio/ordens`       | `ordens/`                |
| `extract_itens_os.py`          | `.../relatorio/itens`        | `itens_os/`              |
| `extract_produtos.py`          | `.../relatorio/produtos`     | `produtos/`              |
| `extract_servicos.py`          | `.../relatorio/servicos`     | `servicos/`              |

O `NOME_ARQUIVO` (`2026-06-08.csv`) e a janela de datas (`DATA_INICIO`, `DATA_FIM`) são **idênticos em todos os scripts** — calculados automaticamente a partir de `date.today()`.

## Tratamento de erros comuns

| Erro                          | Causa provável                               | Solução                                                          |
|-------------------------------|----------------------------------------------|------------------------------------------------------------------|
| `NoSuchElementException`      | Seletor errado ou página ainda carregando    | Use `WebDriverWait` + `EC.presence_of_element_located`           |
| `TimeoutException`            | Página demorou mais que o esperado           | Aumente o timeout do `WebDriverWait`                             |
| `ElementNotInteractableError` | Elemento fora da tela ou coberto por outro   | Use `driver.execute_script("arguments[0].click()", el)`          |
| `KeyError` no `os.environ`    | Variável não definida no `.env`              | Verifique se o `.env` está na raiz e se `load_dotenv()` foi chamado |
| Download não aparece          | Caminho absoluto incorreto no Chrome         | Confirme que `os.path.abspath(download_dir)` resolve o caminho certo |

## Evolução futura — integração com Airflow

Esta seção documenta as alterações que serão feitas nos scripts quando o Airflow for integrado ao pipeline.

### Limitação atual

A janela fixa de 7 dias não cobre gaps causados por falhas. Se o pipeline não rodar numa semana, os registros daquele período são perdidos — não há como recuperá-los automaticamente.

### O que muda com o Airflow

O Airflow passa uma variável `logical_date` para cada execução — a data de referência daquela run, não a data em que o pipeline foi executado. Isso permite rerrodar execuções passadas com os parâmetros originais, cobrindo gaps automaticamente via UI (botão "Clear" na run que falhou).

**Alteração 1 — lógica de datas:**

```python
# ANTES (MVP sem Airflow)
from datetime import date, timedelta
hoje        = date.today()
DATA_FIM    = hoje.strftime("%d/%m/%Y")
DATA_INICIO = (hoje - timedelta(days=7)).strftime("%d/%m/%Y")
NOME_ARQUIVO = f"{hoje.isoformat()}.csv"

# DEPOIS (com Airflow)
def run_extraction(**context):
    logical_date = context["logical_date"]
    DATA_FIM     = logical_date.strftime("%d/%m/%Y")
    DATA_INICIO  = (logical_date - timedelta(days=7)).strftime("%d/%m/%Y")
    NOME_ARQUIVO = f"{logical_date.date().isoformat()}.csv"
```

**Alteração 2 — variáveis de ambiente:**

```python
# ANTES (MVP sem Airflow)
from dotenv import load_dotenv
load_dotenv()
LOGIN_URL = os.environ["SISTEMA_LOGIN_URL"]

# DEPOIS (com Airflow)
from airflow.models import Variable
LOGIN_URL = Variable.get("SISTEMA_LOGIN_URL")
```

**Alteração 3 — assinatura da função:**

```python
# ANTES
def run_extraction():
    ...

if __name__ == "__main__":
    run_extraction()

# DEPOIS
def run_extraction(**context):   # recebe o contexto do Airflow
    ...
```

O restante da lógica — login, navegação, download, renomeação — permanece idêntico.
